Darmowe rozszerzenie do Chrome, które dodaje przycisk „Pobierz dokument” do podglądu PIT-11 – tak jak przy PIT-37. Jedno kliknięcie i masz czysty, poprawnie złożony PDF w formacie A4. A free Chrome extension that adds a “Download document” button to the PIT-11 preview, just like the one on your PIT-37. One click gives you a clean, correctly laid-out A4 PDF.

Jaki problem rozwiązuje?What problem does it solve?

Twój e-PIT pokazuje PIT-11 tylko w podglądzie – nie ma przycisku pobierania. Drukowanie strony przez przeglądarkę daje nachodzące na siebie sekcje, złe podziały stron i znikający pasek przewijania.

Twój e-PIT only shows the PIT-11 as a preview – there is no download button. Printing the page from the browser gives overlapping sections, broken page breaks and a missing scrollbar.

  • 4 strony A4 z numeracją 1/4–4/4, bez nachodzących sekcji
  • 4 A4 pages numbered 1/4–4/4, no overlapping sections
  • Nazwa pliku uzupełniona automatycznie, np. PIT-11_2025_ACME_SP
  • File name filled in for you, e.g. PIT-11_2025_ACME_SP
  • Działa dla każdego roku i każdego płatnika
  • Works for every year and every payer

InstalacjaInstall

Wkrótce w Chrome Web Store. Do tego czasu możesz zainstalować ręcznie: Coming soon to the Chrome Web Store. Until then you can install it manually:

  1. Pobierz archiwum ZIP i rozpakuj je.
  2. Otwórz chrome://extensions i włącz Tryb dewelopera.
  3. Kliknij Załaduj rozpakowane i wybierz folder extension.
  1. Download the ZIP archive and unpack it.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and select the extension folder.

Jak używaćHow to use

  1. Zaloguj się do Twój e-PIT i otwórz Twoje dane źródłowe → PIT-11 → Podgląd.
  2. Kliknij Pobierz dokument.
  3. W oknie drukowania wybierz Zapisz jako PDF, odznacz Nagłówki i stopki i kliknij Zapisz.
  1. Log in to Twój e-PIT and open Your source data → PIT-11 → Preview.
  2. Click Download document.
  3. In the print dialog choose Save as PDF, untick Headers and footers and click Save.

PrywatnośćPrivacy

Rozszerzenie nie zbiera, nie przechowuje i nie wysyła żadnych danych. Odczytuje formularz PIT-11 wyświetlony w Twojej przeglądarce, porządkuje go i otwiera okno drukowania – nic więcej.

  • Działa tylko na epit.podatki.gov.pl
  • Brak dodatkowych uprawnień, brak połączeń sieciowych, brak zdalnego kodu
  • Otwarty kod źródłowy – możesz go sprawdzić na GitHub

The extension does not collect, store or send any data. It reads the PIT-11 form shown in your browser, cleans it up and opens the print dialog – nothing else.

  • Runs only on epit.podatki.gov.pl
  • No extra permissions, no network requests, no remote code
  • Open source – you can review it on GitHub
